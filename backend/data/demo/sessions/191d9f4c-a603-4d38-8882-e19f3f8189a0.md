19.1.4　FrontPage的安全模型
任何直接访问 Web 服务器内容的发布系统都要非常注意其行为的潜在安全影响。
FPSE 在极大程度上是依赖 Web 服务器来提供安全性的。
FPSE 安全模型定义了 3 种用户：管理员、作者以及浏览者，其中管理员拥有完全
控制权。所有权限都是累积的，也就是说，所有的管理员都能编写和浏览 FrontPage
的网站。类似地，所有作者都有浏览权限。
对于给定的由 FPSE 扩展的网站，管理员、作者以及浏览者的列表都要定义好。所
有的子 Web 可以从根 Web 继承权限，也可以自行定义。对于非 IIS 的 Web 服务器，
所有的 FPSE 程序都要保存在标记为“可执行”的目录中（所有其他 CGI 程序也都
有同样的限制）。Fpsrvadm，FrontPage 的服务器管理员实用工具，可以用来进行这
种工作。在 IIS 服务器上，则可用 Windows 操作系统自身集成的安全模型。
在非 IIS 服务器上，Web 服务器的访问控制机制负责指定能够访问指定程序的用户。
在 Apache 和 NCSA 的 Web 服务器上，访问控制文件名为 .htaccess；在 Netscape 服

别的权限关联起来：GET 是读权限，POST 是写权限，等等。例如，为了使用户在

## 🔥 第一阶段 · 第一课：Transformer 核心原理

要系统掌握大模型，**Transformer 是一切的基础**。GPT、LLaMA、Claude、Gemini 都是它的变体。我们今天从最核心的问题开始——

---

### 1. 为什么需要 Transformer？

在 Transformer（2017）之前，序列建模靠 RNN/LSTM。问题在于：
- RNN 是**串行**的，第 t 步必须等第 t-1 步算完，无法并行
- 长距离依赖会梯度消失

Transformer 的核心思想：**彻底抛弃循环，全靠 Attention 机制**，让每个 token 直接和序列中所有 token 交互。

---

### 2. Self-Attention 是怎么工作的？

这是最关键的一步。我们一步一步推导。

#### 2.1 从直觉出发

假设句子是：`"The cat sat on the mat"`

当我们处理 `"cat"` 时，它应该关注哪些词？— `"The"`（冠词）、`"sat"`（猫做了什么）、`"mat"`（间接相关）……

Self-Attention 让每个词生成对整句所有词的**加权关注分数**。

#### 2.2 数学形式

对于每个输入 token 的 embedding 向量 \(x_i\)，我们生成三个向量：

- **Query（Q）**：我要查什么 — \(Q = x \cdot W^Q\)
- **Key（K）**：我有什么标签 — \(K = x \cdot W^K\)
- **Value（V）**：我的实际内容 — \(V = x \cdot W^V\)

Attention 的计算公式：

\[
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
\]

分步骤理解：

> **Step 1**：\(QK^T\) — 每个 token 的 Query 和所有 token 的 Key 做点积，得到「相关性分数矩阵」
>
> **Step 2**：除以 \(\sqrt{d_k}\) — 防止点积过大导致 softmax 梯度消失（缩放因子）
>
> **Step 3**：softmax — 把分数变成概率权重（每行和为 1）
>
> **Step 4**：乘以 V — 用权重加权求和，得到每个位置的输出

---

### 3. 手写 Self-Attention（PyTorch）

下面是核心实现，你可以在本地跑起来：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class SingleHeadAttention(nn.Module):
    def __init__(self, d_model=512, d_k=64):
        super().__init__()
        self.d_k = d_k
        
        # 三个线性变换矩阵
        self.W_Q = nn.Linear(d_model, d_k, bias=False)
        self.W_K = nn.Linear(d_model, d_k, bias=False)
        self.W_V = nn.Linear(d_model, d_k, bias=False)
    
    def forward(self, x):
        """
        x: (batch_size, seq_len, d_model)
        """
        Q = self.W_Q(x)  # (batch, seq_len, d_k)
        K = self.W_K(x)  # (batch, seq_len, d_k)
        V = self.W_V(x)  # (batch, seq_len, d_k)
        
        # 计算注意力分数: QK^T / sqrt(d_k)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        # scores: (batch, seq_len, seq_len)
        
        # softmax 得到注意力权重
        attn_weights = F.softmax(scores, dim=-1)
        
        # 加权求和
        output = torch.matmul(attn_weights, V)
        # output: (batch, seq_len, d_k)
        
        return output, attn_weights
```

### 4. Multi-Head Attention

单头注意力只能捕获一种关系模式。**多头注意力**用多组 \(W^Q, W^K, W^V\) 并行计算，让模型同时关注不同层面的关系（语法、语义、位置等）：

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        assert d_model % n_heads == 0
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        # 合并所有头的 QKV 矩阵，一次线性变换再拆分
        self.W_Q = nn.Linear(d_model, d_model, bias=False)
        self.W_K = nn.Linear(d_model, d_model, bias=False)
        self.W_V = nn.Linear(d_model, d_model, bias=False)
        self.W_O = nn.Linear(d_model, d_model, bias=False)  # 输出投影
    
    def forward(self, x):
        batch_size, seq_len, _ = x.shape
        
        # 线性变换
        Q = self.W_Q(x)  # (batch, seq_len, d_model)
        K = self.W_K(x)
        V = self.W_V(x)
        
        # 拆分成多头: (batch, seq_len, n_heads, d_k) -> (batch, n_heads, seq_len, d_k)
        Q = Q.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        
        # 缩放点积注意力 (每个头独立计算)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        attn_weights = F.softmax(scores, dim=-1)
        attn_output = torch.matmul(attn_weights, V)
        # (batch, n_heads, seq_len, d_k)
        
        # 拼接所有头: (batch, seq_len, d_model)
        attn_output = attn_output.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.d_model
        )
        
        # 最终线性投影
        output = self.W_O(attn_output)
        
        return output
```

### 5. 完整 Transformer Block

现在把 Attention + Feed-Forward + LayerNorm + 残差连接拼起来：

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model=512, n_heads=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, n_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout),
        )
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x):
        # Self-Attention + 残差 + LayerNorm
        attn_out = self.attention(x)
        x = self.norm1(x + self.dropout(attn_out))  # Post-LN: 原始论文写法
        
        # Feed-Forward + 残差 + LayerNorm
        ff_out = self.ff(x)
        x = self.norm2(x + self.dropout(ff_out))
        
        return x
```

> 💡 **关键细节**：LayerNorm 的位置有 **Post-LN**（原始论文，加在残差后）和 **Pre-LN**（现代 LLM 如 GPT-2/LLaMA 更常用，加在 Attention/FF 之前）。Pre-LN 训练更稳定。

## 📝 今日要点总结

| 概念 | 核心理解 |
|------|----------|
| **Self-Attention** | 让每个 token 动态关注序列中所有 token，计算加权表示 |
| **Q / K / V** | Query（查询）、Key（匹配标签）、Value（实际内容），三者都从同一个输入投影而来 |
| **\(\frac{1}{\sqrt{d_k}}\)** | 缩放因子，防止点积方差过大 → softmax 梯度消失 |
| **Multi-Head** | 多组 QKV 并行，捕获不同子空间的关系模式 |
| **残差 + LayerNorm** | 残差让梯度直达底层，LayerNorm 稳定训练 |
| **Feed-Forward** | 两层全连接 + 激活函数，每个位置独立，提供非线性变换能力 |
